PROMOCIÓN 2027 · PWA PARA iPHONE
==================================

QUÉ ES ESTA CARPETA
- index.html: el último index auditado, convertido en aplicación web instalable.
- manifest.webmanifest: datos de la aplicación e iconos.
- sw.js: caché de la interfaz para abrir más rápido y permitir estudiar preguntas sin conexión después de la primera carga.
- icons/: iconos para iPhone/PWA.
- .nojekyll: evita procesamiento innecesario de GitHub Pages.

IMPORTANTE SOBRE LOS AUDIOS
Este paquete NO duplica tus audios. El index conserva exactamente las rutas que ya usa, por ejemplo:
  audios_tactico/...
  Audios_GE/...
  Audios_MOM/...
  Audios_MALOMI/...
Por eso debes conservar en el mismo repositorio las carpetas de audio que ya tienes y sus mismos nombres/rutas.
Los audios no se guardan masivamente en el iPhone: se cargan cuando los reproduces.

CÓMO SUBIRLO A GITHUB
1. En el repositorio donde ya tienes el index y las carpetas de audios, reemplaza el index anterior por el archivo index.html de esta carpeta.
2. Sube además manifest.webmanifest, sw.js, .nojekyll y la carpeta icons.
3. NO borres ni cambies de nombre tus carpetas de audios.
4. En GitHub: Settings > Pages. Publica la rama/carpeta donde está index.html.
5. Abre la URL de GitHub Pages en Safari del iPhone.

CÓMO INSTALARLO EN iPHONE
1. Abre la URL de GitHub Pages en Safari (no desde el navegador interno de otra app).
2. Pulsa Compartir.
3. Elige “Agregar a pantalla de inicio”.
4. Confirma “Agregar”.
5. Abre “Promoción 2027” desde el icono de la pantalla de inicio.

ACTUALIZACIONES
Cuando sustituyas index.html por una versión nueva en GitHub, la PWA comprobará actualizaciones al abrirse. El sistema usa caché para mostrar rápido la aplicación y actualiza la copia en segundo plano; normalmente la versión nueva aparecerá en la siguiente apertura.

DATOS Y PROGRESO
El progreso sigue guardándose en el almacenamiento local del navegador/PWA, igual que tu index actual. No se sincroniza entre dispositivos todavía.
